Approach

Agents write more of the code every month. Deciding what's worth writing is still the job.

I've worked in agentic workflows daily since they became genuinely useful — OpenAI Codex as the driver, MCP servers for context, agent skills for the parts that repeat. It changed how much ground I cover in a week. It didn't change who is accountable for what ships.

The agent handles

  • first-pass implementations
  • refactors spanning dozens of files
  • test scaffolding and fixtures
  • migrations and dependency bumps
  • wiring, boilerplate, glue code
  • the second, third and fourth attempt

I stay on

  • The architecture — and the constraints the agent works inside.
  • What done actually means for this feature.
  • The review. Every diff, before it lands.
  • The trade-offs I'd still defend in six months.

More surface covered per week, against the same bar for what reaches production.
